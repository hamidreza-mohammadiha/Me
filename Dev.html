⏳ Spillover
Wait → utility loss · future catch drawn from U(0.5v,1.5v) or U(0,2v)
Agent Logic

Behavior & Decision Sets

Concise pseudo‑code for each autonomous agent in the simulation.

🧑 Agent

Customer

# Customer behavior on arrival: observe p_dyn, p_stat, seats_dyn, seats_stat, quality, WTP, urgency if WTP >= p_dyn and seats_dyn > 0: buy_dynamic() else if WTP >= p_stat and seats_stat > 0: buy_static() else: if urgency > threshold: enter_spillover(wait_utility_loss) else: leave_market() # Spillover re‑entry on spillover_return: draw future_value ~ U(low, high) update WTP += future_value re‑evaluate()
Knows own type, WTP, urgency, prices, availability Doesn't know future prices, others' WTP, airline strategies Decisions buy DYN · buy STAT · spillover · leave
📈 Agent

Dynamic Airline

# Dynamic pricing logic on each tick: observe elapsed_time, seats_sold, remaining_capacity, expected_sales, demand_arrival_rate, static_price pace_ratio = elapsed_time / total_time * (remaining_capacity / total_seats) coeff = clamp(pace_ratio * demand_arrival_rate, 0.6, 1.8) price = static_price * pace_ratio * coeff price = clamp(price, min_price, max_price) set_price(price) log(price, pace_ratio, coeff)
Knows own inventory, elapsed time, static price, demand rate Doesn't know individual WTP, competitor's next move Decisions set price (pace‑based, bounded)
⚖️ Agent

Static Airline

# Fixed‑price inventory tracker on each tick: observe incoming_demand, remaining_inventory price = 273 # fixed for each request: if remaining_inventory > 0 and customer.WTP >= price: sell_seat(price) remaining_inventory -= 1 log_sale(price) # Never changes price — only tracks log_inventory(remaining_inventory, incoming_demand)
Knows own price ($273), remaining inventory, demand Doesn't know customer WTP distribution, competitor's strategy Decisions sell if inventory & WTP ≥ price (passive)
